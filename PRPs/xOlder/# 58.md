
### 🛠️ Agent Instruction Plan: Equirectangular Vertex Projection for Legacy Sphere (Aspect-Corrected)

**Objective:** Fix rectilinear perspective distortion (fisheye stretching) in the `sphereDeformation.ts` legacy visualizer when viewed from the inside, ensuring the projection maintains a perfect 1:1 aspect ratio regardless of window/UI resizing.

**Strategy:** Implement a non-linear spherical projection in the vertex shader. When `u_isInsideView` is true, calculate the Yaw and Pitch of each vertex relative to the camera, apply an aspect ratio correction to the X-axis, and map those angles directly to Normalized Device Coordinates (NDC).

#### Step 1: Add Uniforms to the Legacy Material

**File:** `src/visualizer/AmbiScene.ts`

1. **Ensure Uniform Consistency:** Ensure that the `ShaderMaterial` utilizing `sphereDeformation.ts` receives exactly the same uniforms as the volumetric shader for handling view mode and resolution.
* `u_isInsideView`: `{ value: true }`
* `u_resolution`: `{ value: new THREE.Vector2(window.innerWidth, window.innerHeight) }`


2. **Sync State:** Ensure the methods that toggle the view mode and handle window resizing update these uniforms on the legacy material as well.

#### Step 2: Update the Legacy Vertex Shader

**File:** `src/visualizer/shaders/sphereDeformation.ts`

1. **Declare the Uniforms:** At the top of the **Vertex Shader**, add:
```glsl
uniform bool u_isInsideView;
uniform vec2 u_resolution;

```


2. **Modify `gl_Position` Calculation:** Locate the end of the `main()` function where the final vertex position is assigned to `gl_Position`. Replace that final projection step with this conditional logic:
```glsl
// Assuming 'transformed' contains your displaced local vertex position
vec4 worldPosition = modelMatrix * vec4(transformed, 1.0);
vec4 viewPosition = viewMatrix * worldPosition; // Position relative to the camera

if (u_isInsideView) {
    // --- NON-LINEAR SPHERICAL PROJECTION (Inside View) ---

    // 1. Get the direction from the camera to the vertex in view space
    vec3 dir = normalize(viewPosition.xyz);

    // 2. Map direction to Spherical Angles (Yaw and Pitch)
    // In Three.js view space: -Z is forward, +X is right, +Y is up
    float yaw = atan(dir.x, -dir.z); 
    float pitch = asin(dir.y);

    // 3. Aspect Ratio Correction
    // Calculate the aspect ratio to prevent the sphere from squishing
    // when the canvas is not perfectly square (e.g., sidebars opening).
    float aspect = u_resolution.x / u_resolution.y;

    // 4. Define the apparent Field of View scaling factor
    // Match this 'fovScale' to the one used in the volumetric shader
    float fovScale = 1.57079632 * 0.75; 

    // 5. Map angles to Normalized Device Coordinates (NDC: -1.0 to 1.0)
    // We multiply the fovScale by aspect for the X axis to correct the stretching.
    vec2 ndc = vec2(yaw / (fovScale * aspect), pitch / fovScale);

    // 6. Calculate standard clip-space Z and W for depth sorting
    vec4 clipPos = projectionMatrix * viewPosition;

    // 7. Output final position. We multiply ndc by clipPos.w because 
    // WebGL will automatically divide gl_Position.xy by gl_Position.w later.
    gl_Position = vec4(ndc * clipPos.w, clipPos.z, clipPos.w);

} else {
    // --- STANDARD PERSPECTIVE PROJECTION (Outside View) ---
    gl_Position = projectionMatrix * viewPosition;
}

```



#### Step 3: Verification Constraints for Agents

* **Tessellation Requirement:** Non-linear projection requires a highly tessellated mesh so the straight lines between vertices don't look warped. Ensure the legacy `SphereGeometry` has high segment counts (e.g., `widthSegments` and `heightSegments` > 128).
* **Aspect Ratio Test:** Resize the browser window and toggle the UI sidebars. Ensure the sphere deformation remains perfectly round and does not squish into an oval.
