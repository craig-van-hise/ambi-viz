# Product Requirements Prompt (PRP) — [Status Marker] ✅

## 1. Project Context & Objectives
The Step 2 onboarding tooltip ("Start Tracking") is currently rendering behind the main 3D WebGL canvas. The previous attempt to apply a `z-index` to the tooltip component failed due to a CSS Stacking Context conflict. The parent container (`ControlSidebar`) currently has a lower stacking priority than the sibling `MainViewer` container. The objective is to elevate the `ControlSidebar`'s layout layer so all its children (including tooltips) float securely above the 3D canvas.

## 2. Technical Decisions & Dependencies
* **Target Files:** `src/App.tsx` (or the primary layout component that renders both `MainViewer` and `ControlSidebar`).
* **Architectural Action:** Modify the layout wrapper classes using Tailwind to establish proper relative stacking contexts. The Sidebar must have a higher z-index than the Main Viewer.

## 3. Implementation Phases

### Phase 1: Establish Root Stacking Contexts — [Status Marker] ✅ Completed
* **Objective:** Ensure the layout container holding the sidebar is strictly layered above the layout container holding the 3D canvas.
* **Instructions:**
  1. Open the main layout file where both the visualizer and sidebar are instantiated (likely `src/App.tsx` or a dedicated Layout wrapper).
  2. Locate the wrapper `div` or `<aside>` that contains the `<ControlSidebar />`.
  3. Apply the Tailwind classes `relative z-20` (or `z-40`, depending on your existing scale) to this sidebar wrapper.
  4. Locate the wrapper `div` or `<main>` that contains the `<MainViewer />` (the 3D canvas).
  5. Apply the Tailwind classes `relative z-0` (or ensure it does not have a higher z-index than the sidebar) to the viewer wrapper.
