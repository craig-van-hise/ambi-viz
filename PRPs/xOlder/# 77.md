# Product Requirements Prompt (PRP) — [Status Marker] ✅

## 1. Project Context & Objectives
During the recent refactor to move the "Start Tracking" button to the top of the `ControlSidebar`, incorrect styling instructions were applied, resulting in a massive, bright blue, full-width button that breaks the application's design system. The objective of this fix is to retain the button's new position at the top of the sidebar but entirely revert its visual styling to its original, subtle state.

## 2. Technical Decisions & Dependencies
* **Target File:** `src/components/ControlSidebar.tsx`
* **Architectural Action:** Style regression. Strip out the recently added primary button styles (e.g., `w-full`, `bg-blue-600`, etc.) and restore the original Tailwind classes used when the component lived inside the `ViewAndTrackingPanel`.
* **Design Spec:** The button should be a compact, dark-themed toggle (e.g., dark gray/slate background, subtle hover state, standard font weight) containing the camera icon and text, matching the aesthetic of the other nested controls in the application.

## 3. Implementation Phases

### Phase 1: Revert Button Styling — [Status Marker] ✅
* **Objective:** Strip the erroneous "primary action" styling from the Tracking button and restore its original UI footprint.
* **Instructions:**
  1. Open `src/components/ControlSidebar.tsx`.
  2. Locate the "Start Tracking" button element currently sitting under the "CONTROLS" header.
  3. Remove the overarching structural and color classes that were mistakenly added (e.g., `w-full`, `py-3`, `bg-blue-600`, `hover:bg-blue-500`, `font-bold`).
  4. Apply the original styling classes. If you need to reference the Git history for `ViewAndTrackingPanel.tsx` prior to the refactor, do so.   5. Ensure the container holding the button aligns it properly (e.g., flex layout, center alignment) without forcing it to stretch to 100% width unless that was the original behavior (referencing the original screenshot, the button was compact and right-aligned or centered, not full-width).
