# Product Requirements Prompt (PRP)

## 1. Project Context & Objectives
You are tasked with improving the Track Queue UI and UX for the AmbiViz application. Currently, the application has three specific issues in the queue panel:
1. The "X" (remove) button on tracks does not successfully remove them from the queue (likely an event bubbling or state synchronization issue).
2. The currently active track lacks a strong visual indicator, making it hard to distinguish from the rest of the queue.
3. The loading state for buffering tracks is too subtle and relies on an undefined/weak `.loading-dots` class.

Your objective is to fix the event propagation on the delete button, apply a "neon/glow" aesthetic to the active track (mirroring the transport controls), and implement a highly visible, staggered animated ellipsis using Tailwind utility classes.

## 2. Technical Decisions & Dependencies
* **Event Handling:** React's synthetic events can sometimes leak. You will enforce strict `e.preventDefault()` and `e.stopPropagation()` inline on the remove button in `TrackQueue.tsx`.
* **Active Track Styling (Tailwind):** To achieve the "neon glow" without creating new CSS classes, you will utilize Tailwind 4 arbitrary box-shadow values: `shadow-[0_0_12px_var(--color-primary)]` combined with a solid primary border.
* **Animated Ellipsis:** You will discard the external `.loading-dots` class and implement a purely inline staggered animation using Tailwind's `animate-pulse` or inline keyframes. Because standard Tailwind `animate-pulse` affects opacity evenly, you will construct a flex row with 3 separate dots utilizing custom inline styles for `animationDelay`.

    4. * **TDD Checkpoint:**

### Phase 3: "Animated Ellipsis" Loading Indicator
* **Objective:** Create a highly visible, staggered loading animation for tracks that are buffering.
* **Instructions:**
    1. In `src/components/TrackQueue.tsx`, locate the loading state render block (around line 62): `<>Loading<span className="loading-dots"></span></>`.

* **TDD Checkpoint:**
