
### 🛠️ Agent Instruction Plan: Re-Link Zoom Slider to Inside View Shaders

**Objective:** Re-enable the Inside View Zoom slider by passing the Three.js camera's dynamic Field of View (`fov`) into the custom equirectangular shaders (both volumetric and legacy).

#### Step 1: Add the `u_fov` Uniform to the Materials

**File:** `src/visualizer/AmbiScene.ts`

1. **Declare the Uniform:** In the uniform initializations for **both** your volumetric `ShaderMaterial` and your legacy `sphereDeformation` material, add a new `u_fov` property:
```javascript
u_fov: { value: 90.0 }, // Or whatever your default camera FOV is

```


2. **Sync in the Render Loop:** In your main `animate()` or `render()` loop where you update uniforms every frame (where you currently update `u_cameraWorldMatrix`), add this line so the shader always knows the exact zoom level of the camera:
```javascript
// Assuming 'this.camera' is your PerspectiveCamera
this.material.uniforms.u_fov.value = this.camera.fov;

// Do the same for the legacy material if it is currently active
if (this.legacyMaterial) {
    this.legacyMaterial.uniforms.u_fov.value = this.camera.fov;
}

```



#### Step 2: Update the Volumetric Shader

**File:** `src/visualizer/shaders/ambisonic.ts`

1. **Declare Uniform:** At the top, add:
```glsl
uniform float u_fov;

```


2. **Replace Hardcoded FOV:** Inside the `if (u_isInsideView)` block, replace the hardcoded `fovScale` with a dynamic calculation based on `u_fov`:
```glsl
// Convert the camera's FOV from degrees to radians, 
// and divide by 2.0 to get the half-angle needed for the math.
float fovScale = (u_fov * 3.14159265 / 180.0) * 0.5;

float yaw = uv.x * fovScale;   
float pitch = uv.y * fovScale; 

```



#### Step 3: Update the Legacy Sphere Shader

**File:** `src/visualizer/shaders/sphereDeformation.ts`

1. **Declare Uniform:** At the top of the **Vertex Shader**, add:
```glsl
uniform float u_fov;

```


2. **Replace Hardcoded FOV:** Inside the `if (u_isInsideView)` block, replace the hardcoded `fovScale` with the exact same dynamic calculation:
```glsl
// Convert FOV to radians and get the half-angle
float fovScale = (u_fov * 3.14159265 / 180.0) * 0.5;

// (Keep your existing aspect ratio logic below this)
vec2 ndc = vec2(yaw / (fovScale * aspect), pitch / fovScale);

```
