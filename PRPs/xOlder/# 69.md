
### 🤖 Prompt for your Agent:

**Objective:** Configure and deploy this Vite-based React project to GitHub Pages using GitHub Actions.

Please execute the following steps in order:

**Step 1: Update Vite Configuration**

1. Read the current repository name from the local `.git` configuration or request it from the user if unavailable.
2. Open `vite.config.ts`.
3. Add the `base` property inside the `defineConfig` object. The value must be the repository name wrapped in forward slashes (e.g., `base: '/<REPO_NAME>/',`).

**Step 2: Create the GitHub Actions Workflow**

1. Create a new directory structure in the root of the project: `.github/workflows/`.
2. Inside the `workflows` directory, create a new file named `deploy.yml`.
3. Populate `deploy.yml` with the following YAML configuration:

```yaml
name: Deploy static content to Pages

on:
  push:
    branches: ['main', 'master'] 

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: 'pages'
  cancel-in-progress: true

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
      - name: Set up Node
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'
      - name: Install dependencies
        run: npm install
      - name: Build
        run: npm run build
      - name: Setup Pages
        uses: actions/configure-pages@v4
      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: './dist'
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4

```

**Step 3: Commit and Push Changes**

1. Stage the modified `vite.config.ts` and the new `.github/workflows/deploy.yml` file.
2. Commit the changes with the message: `chore: configure GitHub Pages deployment workflow`.
3. Push the commit to the remote repository.

**Step 4: Configure GitHub Pages Settings**
*Note: If you (the agent) have GitHub CLI (`gh`) access and sufficient permissions, execute the following configuration via CLI. Otherwise, output these instructions for the user to complete manually:*

1. Navigate to the repository settings on GitHub.
2. Go to the "Pages" section in the left sidebar.
3. Under "Build and deployment", set the "Source" dropdown to "GitHub Actions".
