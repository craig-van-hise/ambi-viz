# Product Requirements Prompt (PRP) — [Status Marker] ✅

## 1. Project Context & Objectives
The onboarding tooltips (Steps 2 and 3) are functionally positioned but lack the necessary visual prominence to effectively guide first-time users. The current design is too small and subtle. The objective is to overhaul the `AnimatedPointer` component's styling to make the tooltips significantly larger, bolder, and impossible to ignore, drawing immediate attention to the required actions.

## 2. Technical Decisions & Dependencies
* **Target File:** `src/components/onboarding/AnimatedPointer.tsx`
* **Architectural Action:** UI Scaling and Enhancement. Modify the existing Tailwind utility classes to increase the component's footprint.
* **Design Spec:**
  * **Typography:** Increase from standard/small text to at least `text-lg` or `text-xl` with a `font-bold` or `font-extrabold` weight.
  * **Spacing:** Double the horizontal and vertical padding (e.g., `px-6 py-3` or `px-8 py-4`).
  * **Iconography:** Scale up the arrow icon significantly (e.g., if using an SVG/Lucide icon, set `size={32}` or `w-8 h-8`; if text, use `text-2xl` or `text-3xl`).
  * **Effects:** Add a pronounced, colorful drop-shadow/glow (e.g., `shadow-[0_0_20px_rgba(56,189,248,0.6)]`) or a slightly brighter background gradient to make the dark pill stand out against the main canvas.

## 3. Implementation Phases

### Phase 1: Scale Up Tooltip UI — [Status Marker] ✅ Completed
* **Objective:** Increase the physical size and visual weight of the `AnimatedPointer` component.
* **Instructions:**
  1. Open `src/components/onboarding/AnimatedPointer.tsx`.
  2. Locate the main wrapper `div` (or `motion.div`) that forms the background pill.
  3. Update the padding classes (e.g., change `px-3 py-1.5` to `px-6 py-3`).
  4. Update the typography classes on the text element (e.g., `text-lg font-bold tracking-wide`).
  5. Update the sizing of the arrow icon element to match the new text scale (e.g., `w-8 h-8` or `text-2xl`).
  6. Add a vibrant box-shadow glow to the parent container to lift it off the background (e.g., `shadow-lg shadow-cyan-500/50` or a custom arbitrary shadow).
  7. *Optional but recommended:* If you are using `framer-motion` for a bouncing/pulsing effect, slightly increase the translation distance (e.g., bouncing 10px instead of 5px) to make the animation more aggressive.
* **TDD Checkpoint:**
  * **Test Case 1:** [Given the `AnimatedPointer` is rendered, When inspecting the DOM, Assert that the updated scaling classes (like `text-lg`, `px-6`, etc.) are present on the component's elements.]
  * **Status Update:** "Transition Phase status to 🔵 Active. Apply the styling enhancements. Update status to ✅ Completed before initiating subsequent phases."
  * **User Verification:** "[USER VERIFICATION REQUIRED] Trigger the tutorial and advance to Step 2. Verify visually that the tooltip is significantly larger, the arrow is more prominent, and the overall component grabs your attention much faster."
