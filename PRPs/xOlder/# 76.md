# Product Requirements Prompt (PRP) — [Status Marker] 🔵

## 1. Project Context & Objectives
The user experience of the AmbiViz application is being streamlined to emphasize its core feature: webcam-based head tracking. Currently, the "Start Tracking" button is nested within the "View & Tracking" collapsible panel. This refactor will extract the tracking controls to the top of the `ControlSidebar`, aligning it with the user's primary workflow. The legacy panel will be renamed to "View" and set to a collapsed state by default to reduce visual clutter.

## 2. Technical Decisions & Dependencies
* **Target Files:** * `src/components/panels/ViewAndTrackingPanel.tsx` (to be renamed)
  * `src/components/ControlSidebar.tsx`
* **Architectural Action:** Component decoupling. The head tracking state and toggle logic will remain in `App.tsx` or `ControlSidebar.tsx` (depending on where the state currently lives), but the UI presentation will move from a nested panel to a standalone, prominent button layout directly under the main sidebar header.
* **Styling Strategy:** Use existing Tailwind utilities to make the standalone tracking button visually distinct and full-width within the sidebar padding.

## 3. Implementation Phases

### Phase 1: Component Extraction & Renaming — [Status Marker] ✅
* **Objective:** Remove tracking elements from the existing panel and rename the component to reflect its new, narrower scope.
* **Instructions:**
  1. Rename the file `src/components/panels/ViewAndTrackingPanel.tsx` to `src/components/panels/ViewPanel.tsx`.
  2. Inside `ViewPanel.tsx`, rename the functional component from `ViewAndTrackingPanel` to `ViewPanel`.
  3. Remove all UI elements related to "Head Tracking" (the label, the toggle button, and any immediate wrapper `div`s).
  4. Remove tracking-related props (e.g., `isTracking`, `onToggleTracking`) from the component's interface/props signature.
  5. Change the panel's display title/header text from "View & Tracking" to simply "View".
* **TDD Checkpoint:**
