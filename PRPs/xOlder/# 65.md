## UI Correction Brief: Visualizer Controls Integration

**Project Status:** Critical UI Refactor Required
**Subject:** Redundancy Elimination and Dynamic Control Mapping

---

### **Executive Summary of UI Defects**

The recent implementation resulted in **functional duplication** and **layout fragmentation**. Specifically, new control modules were appended as separate entities rather than being integrated into the existing architectural framework of the right sidebar.

---

### **Required Structural Corrections**

#### **1. Component Consolidation (The "Visualizer Controls" Section)**

The UI currently contains two "Visualizer Controls" sections. These must be merged into a single, dynamic container located on the **right sidebar, below Camera Position**.

| Feature | Current Error | Corrected Action |
| --- | --- | --- |
| **Section Header** | Duplicate "Visualizer Controls" sections exist. | Retain only the **original** container. |
| **Control Logic** | New sphere controls exist in a static, new section. | **Migrate** sphere controls into the original section. |
| **Visibility** | Both sets of controls are visible simultaneously. | Implement a **conditional swap** based on the active mode. |

#### **2. Redundancy Removal (Mode Switching)**

A secondary, redundant toggle was introduced that conflicts with the established system navigation.

* **Remove:** The new switch labeled "Volumetric and Deformation."
* **Retain:** The original "Volumetric and Sphere" toggle.
* **Dependency:** Ensure all visualization logic remains tied exclusively to the original toggle.

---

### **Functional Logic Workflow**

The UI must respond dynamically to the state of the **Visualization Mode** toggle:

1. **IF Mode = "Volumetric":**
* The "Visualizer Controls" section displays the legacy volumetric adjustment parameters.


2. **IF Mode = "Sphere":**
* The "Visualizer Controls" section hot-swaps the content to display the new sphere-specific parameters (e.g., deformation settings).



---

### **Action Items for Handoff**

* [ ] **Delete** the newly created "Visualizer Controls" UI block.
* [ ] **Delete** the "Volumetric and Deformation" redundant toggle.
* [ ] **Refactor** the original "Visualizer Controls" container to support conditional rendering of child components.
* [ ] **Map** the new sphere control functionality to the migrated inputs within the original container.
