# Product Requirements Prompt (PRP) — [Status Marker] ✅

## 1. Project Context & Objectives
The AmbiViz application currently leverages Google's Open Binaural Renderer (OBR) via WebAssembly to handle Order 1-3 Ambisonic decoding. To ensure compliance with open-source licensing and provide proper credit, we need to update the application's informational UI to include explicit attribution for the OBR project. The target component for this addition is the existing `InfoModal.tsx`.

## 2. Technical Decisions & Dependencies
* **Target File:** `src/components/InfoModal.tsx`
* **Architectural Decision:** Introduce a dedicated "Attributions" or "Acknowledgments" section within the modal. This ensures that as the project scales and incorporates other specialized libraries (like MediaPipe), there is a designated UI region for licensing and credit.
* **Content:** The attribution must explicitly name "Google Open Binaural Renderer (OBR)", state its function within the app (Ambisonic decoding), and provide standard open-source attribution (e.g., Apache 2.0 reference and link to the source repository, if applicable).
