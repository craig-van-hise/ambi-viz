
### 🛠️ Agent Instruction Update: Fix Aspect Ratio Squishing

**Objective:** Correct the equirectangular ray generation in `ambisonic.ts` so that the visualization maintains a 1:1 aspect ratio and does not stretch or squish when the canvas resizes.

**File to modify:** `src/visualizer/shaders/ambisonic.ts`

1. **Locate the Equirectangular Block:** Find the `if (u_isInsideView)` block added in the previous step.
2. **Update the UV Math:** Replace the UV, Yaw, and Pitch calculations with the following code. The key additions are the `aspect` calculation and using a single `fovScale` for both axes.

```glsl
if (u_isInsideView) {
    // --- EQUIRECTANGULAR / SPHERICAL PROJECTION ---
    
    // 1. Normalize screen coordinates to range [-1.0, 1.0]
    vec2 uv = (gl_FragCoord.xy / u_resolution.xy) * 2.0 - 1.0;
    
    // 2. ASPECT RATIO CORRECTION (The Fix)
    // Multiply the X coordinate by the aspect ratio.
    // This ensures a circle stays a circle regardless of window size.
    float aspect = u_resolution.x / u_resolution.y;
    uv.x *= aspect; 
    
    // 3. Map UVs to Spherical Angles
    // Use a SINGLE scaling factor for both axes to maintain perfect proportions.
    // 1.57079632 is PI/2. Adjust this single value to change your base zoom/FOV.
    float fovScale = 1.57079632 * 0.75; 
    
    float yaw = uv.x * fovScale;   
    float pitch = uv.y * fovScale; 
    
    // 4. Convert Spherical to Local Cartesian (Three.js standard: -Z is forward)
    vec3 localDir = vec3(
        cos(pitch) * sin(yaw),
        sin(pitch),
        -cos(pitch) * cos(yaw)
    );
    
    // 5. Transform local ray by camera's world rotation matrix
    rd = normalize(mat3(u_cameraWorldMatrix) * localDir);
    
}

```
