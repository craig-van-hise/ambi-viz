

### 🛠️ Agent Instruction Update: Fix Legacy Sphere Cropping & Wavy Edges

**Objective:** Resolve the frustum culling artifacts (black borders on widescreen and wavy/jagged polygon tearing) in the `sphereDeformation.ts` Inside View by moving the manual depth-cull safely off-screen.

**File to modify:** `src/visualizer/shaders/sphereDeformation.ts`

1. **Locate the Manual Back-Face Cull Block:** Find the `if (u_isInsideView)` block in the vertex shader, specifically the `zDepth` culling logic near the end of the block.
2. **Replace the Culling Logic:** Replace the aggressive `dir.z > 0.0` condition with a yaw-based boundary check.

```glsl
    // ... inside the if (u_isInsideView) block ...
    
    vec2 ndc = vec2(yaw / (fovScale * aspect), pitch / fovScale);
    
    float zDepth = 0.5;
    
    // --- FIX FOR CROPPING & WAVY EDGES ---
    // The previous code (dir.z > 0.0) culled the geometry strictly at 90 degrees.
    // Widescreen monitors require > 90 degrees to fill the horizontal bounds, 
    // which caused the black boxes and exposed the jagged polygon tearing.
    // Now, we only cull the extreme back seam (yaw ≈ PI) to prevent screen-spanning 
    // wrapping artifacts. 3.1 radians is ~177 degrees. This pushes the jagged mesh 
    // boundary completely off-screen, allowing WebGL to cleanly clip the screen edges.
    
    if (abs(yaw) > 3.1) {
        zDepth = 2.0; 
    }
    
    gl_Position = vec4(ndc, zDepth, 1.0);

```
