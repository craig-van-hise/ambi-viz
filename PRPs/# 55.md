## **Technical Brief: Transport & Playhead Synchronization Defects**

The current transport system exhibits critical failures in state management between the UI scrubber and the internal audio engine. The following issues must be resolved to achieve professional-grade playback functionality.

---

### **Primary Defect Categories**

| Feature | Observed Behavior (Bug) | Expected Behavior (Fix) |
| --- | --- | --- |
| **Paused Seek** | Resuming playback ignores new scrubber position; reverts to the previous pause point. | Playback must initialize from the updated `currentTime` defined by the scrubber. |
| **Active Seek** | Moving playhead during playback causes it to "snap back" to the previous position; audio output fails. | Playhead should remain at the new coordinates; audio engine must seek and continue playback seamlessly. |
| **Stop Command** | Audio stops and internal playhead resets to $0$, but the UI scrubber remains at the exit position. | The UI scrubber must visually reset to the start point $(0:00)$ upon a Stop trigger. |

---

### **Identified Functional Requirements**

#### **1. State Synchronization**

* **Logic Alignment:** The internal audio playhead and the visual scrubber are currently decoupled. They must share a single source of truth for the timeline position.
* **Resume Logic:** Ensure the "Play" command polls the current scrubber position immediately before initiating the audio buffer.

#### **2. Real-time Interaction (Scrubbing)**

* **Snap-back Prevention:** Disable any logic that forces the playhead back to a "cached" position during active playback.
* **Audio Continuity:** Fix the audio dropout occurring during/after a seek event to ensure the stream resumes at the new timestamp.

#### **3. Transport UI Updates**

* **Visual Reset:** Implement a listener on the `Stop` function that forces the scrubber UI component to return to the origin.
* **Professional Standards:** Ensure all transport actions (Play, Pause, Stop, Seek) reflect an instantaneous and accurate relationship between the user interface and the underlying audio engine.
