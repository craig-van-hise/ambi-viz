
### **PRP: Redesigning the Information Modal Header**

> **Task Description:** Redesign the header section of the information modal to improve visual hierarchy and professional appearance.

* **Header Container:** Create a main container for the entire modal header. Set its display to flex and `flex-direction: column`, ensuring generous and consistent vertical padding throughout.
* **Top Row Control Bar:** Create a horizontal flexbox container for the top control elements. Set `justify-content: space-between` and `align-items: center` for balanced placement.
* **Left Element:** Place the existing "About AmbiViz" title, including the info icon and text, in the left section of this control bar.
* **Right Element:** Place the standard close (X) icon in the right section of this control bar.


* **Centered Branding Section:** Below the Top Row Control Bar, create a distinct column flexbox container focused on central alignment for the new branding elements.
* **Centered Logo:** Position the Virtual Virgin logo centrally within this section.
* **Scale the Logo:** Critically, increase the scale of the Virtual Virgin logo significantly. Explicitly increase its width/max-width to a multiplier of its current size (e.g., 2x to 3x) while maintaining its proportions.
* **Centered Author Bylines:** Below the centered and enlarged logo, place the centered text "Created by Craig Van Hise".


* **Overall Styling and Spacing:**
* Ensure there is generous, pleasing vertical spacing and clear separation between all elements within the entire header structure.
* Maintain proper visual hierarchy, legibility, and dark theme consistency throughout the new header design.
