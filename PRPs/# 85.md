# Product Requirements Prompt (PRP) — [Status Marker] ✅

## 1. Project Context & Objectives
The Step 3 onboarding tooltip ("Press Play") is currently misaligned. In the previous adjustment, it was shifted too far to the left, causing the arrow to point at the "Previous Track" button rather than the "Play" button. The objective is to correct this horizontal alignment once and for all by properly targeting the Play button.

## 2. Technical Decisions & Dependencies
* **Target File:** `src/components/TransportControls.tsx`
* **Architectural Action:** CSS Stacking and Anchoring correction.
* **Design Spec:** Shift the tooltip to the right by approximately one button width. The most robust method is to make the wrapper of the Play button itself `relative` and attach the absolute-positioned tooltip there. If the tooltip must remain at the transport container level, the horizontal offset (`left` or `translate-x`) must be explicitly adjusted rightward so the arrow centers precisely over the second button in the group (`[ > ]`).

## 3. Implementation Phases

### Phase 1: Lock Tooltip to Play Button — [Status Marker] ✅ Completed
* **Objective:** Center the arrow exactly over the Play button.
* **Instructions:**
  1. Open `src/components/TransportControls.tsx`.
  2. Locate the `<AnimatedPointer>` for Step 3.
  3. **Option A (Best Practice):** Move the tooltip component so it is a direct child of the Play button's specific wrapper container (if one exists). Ensure that wrapper has `position: relative`. Then, set the tooltip to `absolute bottom-full left-1/2 -translate-x-[15%]` (adjusting the translate so the arrow, which is on the left of the tooltip, sits at the 50% mark).
  4. **Option B (Container Level):** If the tooltip must stay where it is in the DOM, reduce its leftward shift. For example, if it currently uses `left-0` or a heavy negative translate like `-translate-x-1/2`, nudge it to the right by adding a specific margin (e.g., `ml-12` or `left-[50px]`) so the arrow completely clears the "Previous" button and lands on the "Play" button.
